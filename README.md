# Sign language translator
A tool built with python using libraries as mediapipe and openCV

This program uses the RandomForestClassifier model. It is trained after a CSV file that has 400 samples of each sign with their 21 landmarks. Should be noted that the samples only are taken from a right hand front. This means that if you want to sign with the left and you need to use the back side of the hand.

The program has the english alphabet and three tool sign being:  
Clear which clears the word string  
Space which add a space between the exsisting word and the new word  
Remove which removes everything.
